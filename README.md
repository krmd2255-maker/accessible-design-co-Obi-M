1. What accessibility challenges did you face, and how did you address them?
One of the challenges I faced was making sure that the website could be used by people with different abilities.
I had to pay attention to color contrast, and making form fields easy to understand.

2. How did you ensure that your design was responsive and accessible to all users?
I used semantic HTML elements such as header, nav, main, section, article, and footer to give the website a clear structure. In addition, I included form labels, descriptive navigation labels, and visible keyboard focus indicators to improve accessibility.

3. What tools or resources did you find most helpful during this project?
The most helpful tools were Visual Studio Code and my web browser. I used Visual Studio Code to write and organize my HTML and CSS files,
while the browser allowed me to preview the website and test how it looked. I also found the WebAIM Contrast Checker helpful for checking color contrast.
